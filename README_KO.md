# 제국의 투쟁 — 실행 안내

[English / 한국어 프로젝트 소개](README.md)

GMT Imperial Struggle의 기존 Godot 프로젝트를 이어서 만든 Windows 플레이 버전이다. 영국 또는 프랑스로 AI와 대전하거나, 한 컴퓨터에서 두 사람이 번갈아 플레이할 수 있다.

## 바로 시작

1. 이 폴더의 `RUN.BAT`를 두 번 클릭한다.
2. 제목 화면에서 기본 AI 또는 전략 AI의 계산 예산을 고른 뒤 영국으로 혼자 하기, 프랑스로 혼자 하기, 로컬 2인 중 하나를 선택한다.
3. 내각 2장을 선택하고 확인한다. 로컬 2인에서는 표시된 진영의 플레이어가 준비 버튼을 눌러 자기 카드를 연다.
4. 투자 타일을 고른 뒤 화면 오른쪽 안내에 따라 이벤트와 행동을 진행한다.

현재 PC에 설치된 Godot 4.7.2를 사용한다. 별도의 설치형 EXE 배포본은 아니다. 다른 PC에서는 Godot 4를 설치하고 `godot_project/project.godot`를 열어 실행하거나, 환경 변수 `GODOT_EXE`에 Godot 실행 파일의 경로를 지정한다. 실제 검증한 엔진은 4.7.2이며 다른 버전은 별도 검증하지 않았다.

## 전략 AI

기본값은 전략 AI 20초다. 10·20·30초는 라운드 전체의 계산 예산이며, 실제 행동 표시 시간은 별도다. 계산 중에도 저장할 수 있고 메뉴로 돌아가면 계산을 중단한다. 불러오기에서는 이미 사용한 계산 시간을 포함해 재개한다. 지금 결정 버튼은 현재까지 찾은 계획으로 기다리기를 끝낸다.

[전략 AI의 원리와 구현](docs/AI_IMPLEMENTATION.md)에 보상 변화 평가, 독립 계산, 숨은 정보 처리와 한계를 설명했다.

## 한국어와 영어

제목 화면의 언어 버튼으로 한국어와 영어를 바꾼다. 선택한 언어는 다음 실행에도 유지된다. 진행 중에는 메뉴로 돌아가 언어를 바꾼 뒤 게임으로 복귀할 수 있다. 언어를 바꾸어도 손패·내각 선택·행동점수·저장 상태는 유지된다.

영어에서는 카드와 내각의 영어 원문, 전체 행동 이름, 자원·보상·선택 안내를 표시한다. 영어의 긴 보상 문구는 두 줄로 표시하고, 손패의 긴 요약은 상세 보기에서 끝까지 읽는다. 한국어·영어 UI 완주와 실제 버튼·저장 재개를 검사했다. 영어 화면 기록은 `output/screenshots/en`에 있다.

## 저장과 재개

상단의 가용 채무는 추가로 빌릴 수 있는 양이다. 함대는 전체 수와 해군 상자의 대기 수를 함께 표시한다. 수요 칸에는 승점·조약점수·채무 증감을, 지역 칸에는 기본 보상과 필요한 지배 공간 차이를 표시한다. 보상 칸에 마우스를 올리면 양국의 현재 시장·지배 공간 수를 확인할 수 있다.

중앙 해군 상자는 대기 함대 말, 대기 수, 지도 배치 수와 미건조 수를 표시한다. 지도에 인쇄된 해군 상자에도 같은 대기 함대가 나타나고 확대·이동에 따라 함께 움직인다. 대기 0척이면 말을 비우며, 귀환 예정 함대는 아직 포함하지 않는다. 중앙의 진영 행에 마우스를 올리면 귀환 예정·영구 제거 수도 확인할 수 있다.

세계 수요에는 원작 상품 그림을 붙였다. 우승 잔은 승점, 문서는 조약점수, 겹친 동전은 채무를 뜻하며 지역 보상도 같은 아이콘을 사용한다. 아이콘 옆에 전체 이름과 숫자를 병기한다. 채무 +1은 빚이 늘어남, −1은 빚이 줄어듦을 뜻한다.

외교 카드 뽑기는 외교 3점을 한 번에 지출한다. 보조 외교의 기본 2점에 조약점수 1점을 보충해 뽑을 수도 있다. 보조 행동은 한 번만 지출할 수 있고, 지역·대상 제한이 붙은 점수는 일반 카드 구입에 쓸 수 없다. 뽑기 더미가 비어 있으면 구입할 수 없으며, 이 행동으로 버림 더미를 재혼합하지 않는다. 새 카드는 다음 행동 라운드부터 사용한다. 카드 정보를 본 이후에는 이전 행동을 되돌려 재추첨할 수 없다 (§5.5.3).

내각 선택 창 오른쪽에서 이번 손패를 함께 볼 수 있다. 카드 이미지나 상세 보기 버튼을 눌러 효과를 읽고 닫으면 선택 중인 내각 창으로 돌아간다.

내각은 처음에 비공개다. 관련 행동에 비공개 내각의 혜택을 쓸 수 있으면 공개하고 진행 또는 비공개 유지를 묻는다. 유지하면 그 혜택을 제외하고 처리하며, 일반 비용이 부족하면 행동을 실행하지 않는다. 자기 행동 라운드에는 타일을 고르기 전에도 미리 공개할 수 있다. 전쟁·득점·상대 라운드에는 새로 공개할 수 없으므로 그때 필요한 내각은 미리 공개해야 한다 (§3.5).

자신의 내각 그림이나 설명을 보는 것만으로는 공개되지 않는다. 하단 내각의 공개됨/비공개 표시가 실제 공개 상태다.

종료하기 전에 저장 버튼을 누른다. 저장 성공 안내를 확인한 뒤 메뉴에서 나간다. 다음 실행에서 불러오기를 선택하면 저장 시점으로 돌아간다. 메뉴 이동 자체가 저장을 뜻하지는 않는다.

저장 위치는 Windows의 `%APPDATA%\Godot\app_userdata\Imperial Struggle\saves\autosave.json`이다. 파일 이름은 autosave이지만 현재 UI에서는 저장 버튼으로 갱신하는 단일 슬롯이다. 직전 파일은 `.bak`으로 보존한다.

뽑은 보너스 타일의 배치, 기본 타일 교체, 이벤트 선택, 전쟁의 영토 양도 거부 대기 상태도 저장된다. 옛 v1 저장은 필요한 진행 정보가 없어 불러오지 않는다. 원본 파일은 삭제하지 않는다.

## 검증 재실행

PowerShell에서 이 폴더를 연 뒤 다음을 실행한다.

```powershell
.\VERIFY.ps1
```

다른 엔진 경로를 쓸 때는 다음처럼 지정한다.

```powershell
.\VERIFY.ps1 -GodotExe 'C:\Tools\Godot\Godot.exe'
```

검사는 별도 사용자 데이터 폴더를 사용하므로 실제 저장을 덮지 않는다. 결과는 `output/validation/summary.json`과 검사별 로그에 남는다. 대표 화면은 `output/screenshots`에 있다.

## 현재 범위

기본 전체 게임, 41개 이벤트, 26개 내각, 22개 이점, 평화 턴과 4개 전쟁, 최종 승패, 기본·전략 AI, 로컬 2인, 저장·재개를 연결했다. 한국어는 Windows 맑은 고딕을 우선 사용하며 대표 글리프를 검사한다. 기본 창 크기는 1600×900이다.

온라인 대전, 별도 시나리오 선택과 선택 규칙 설정, 설치형 배포 패키지는 다음 버전의 범위다. 자동 검사를 통과했다는 사실이 모든 카드 조합의 규칙 정확성이나 AI의 실력을 보증하지는 않는다.
